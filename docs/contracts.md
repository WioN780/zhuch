## 1. Observation vector — 82 float32, world-aligned frame

Built per bot tank each decision tick by `backend/pkg/bots/obs.go::BuildObservation(game, tank, buf []float32)`.

Indices 0–9 — own state:

| idx | value | normalization |
|---|---|---|
| 0 | health fraction | health / maxHealth, [0,1] |
| 1 | vel.X | / TankMaxSpeed |
| 2 | vel.Y | / TankMaxSpeed |
| 3 | sin(orientation) | — |
| 4 | cos(orientation) | — |
| 5 | fire cooldown remaining | remaining ticks / TankFireCooldown, clipped [0,1]; 0 = ready |
| 6 | dist to left wall (x) | / ViewRange, clipped [0,1] |
| 7 | dist to right wall (MapWidth − x) | / ViewRange, clipped [0,1] |
| 8 | dist to top wall (y) | / ViewRange, clipped [0,1] |
| 9 | dist to bottom wall (MapHeight − y) | / ViewRange, clipped [0,1] |

Indices 10–81 — K=8 nearest entities (excluding self) within ViewRange, sorted ascending by distance, 9 floats each. Slots without an entity are all zeros.

Per-entity layout (offset o = 10 + 9·k):

| off | value | normalization |
|---|---|---|
| o+0 | rel pos X (other − self) | / ViewRange |
| o+1 | rel pos Y | / ViewRange |
| o+2 | rel vel X (other − self) | / BulletMuzzleSpeed |
| o+3 | rel vel Y | / BulletMuzzleSpeed |
| o+4 | is_tank | one-hot |
| o+5 | is_bullet | one-hot (all bullets, own included) |
| o+6 | is_food | one-hot |
| o+7 | bounding radius | / TankRadius |
| o+8 | health fraction | health / maxHealth |

## 2. Action vector — 5 float32 (raw network output)

Applied by `backend/pkg/bots/act.go::Apply(out []float32, tank, game)`:

- `InputVector = (tanh(out[0]), tanh(out[1]))`; if |v| > 1, normalize to unit length.
- `Orientation = atan2(out[3], out[2])` (note order: out[2]=cos-component, out[3]=sin-component).
- Fire iff `out[4] > 0` (respects engine cooldown; bullet appended via `Game.SpawnBullet`).

Action-repeat: bots decide every 4 ticks (5 Hz at 20 TPS), staggered by `Offset = botIndex % 4`. Between decisions the last InputVector/Orientation persist; fire is only attempted on decision ticks.

## 3. MLP + weight file format

- Architecture: sizes `[82, 64, 64, 5]`, tanh on hidden layers, raw (identity) output. Param count 9797.
- Flat weight vector, layer-major: for each layer l: `W_l` row-major with shape (out, in) — row i = incoming weights of output unit i — followed by bias `b_l` (len out).
- Forward math in **float64** internally; weights stored as **float32 little-endian**.
- Model file = single JSON document:

```json
{"format": "zhuch-mlp", "version": 1, "sizes": [82,64,64,5],
 "sha256": "<hex sha256 of the raw little-endian float32 weight bytes>",
 "weights_b64": "<base64 of those bytes>"}
```

Go loader: `backend/pkg/brain`. Python reference: `training/zhuch_train/policy_ref.py`.

## 4. Arena HTTP API (`backend/cmd/arena`)

`POST /eval` — run one headless episode, no ticker, full speed.

Request:
```json
{"seed": 123, "max_ticks": 1800,
 "config_overrides": {"map_width": 1500},
 "tanks": [
   {"name": "cand", "weights_b64": "..."},
   {"name": "opp1", "weights_b64": "...", "spawn": {"x": 400, "y": 400}},
   {"name": "s1", "scripted": true}
 ]}
```
- `config_overrides` optional: JSON-unmarshaled over `engine.DefaultConfig()` (fields present overwrite; absent keep defaults).
- `spawn` optional; default = seeded-random position with 100-unit wall margin (deterministic per seed).
- `tanks[0]` is the candidate: episode ends when it dies or at `max_ticks`.

Response:
```json
{"ticks": 1740,
 "tanks": [{"name": "cand", "score": 250, "kills": 1, "death_tick": -1, "alive": true}]}
```
`death_tick` = −1 if alive at episode end. Raw stats only — fitness composition lives in Python.

`POST /eval_batch` — `{"jobs": [<eval request>...]}` → `{"results": [<eval response>...]}` in order; executed on a GOMAXPROCS-bounded worker pool.

`POST /forward` — parity-test endpoint: `{"sizes": [...], "weights_b64": "...", "input": [82 floats]}` → `{"output": [5 floats]}`.

`GET /healthz` → 200 `ok`.
Reserved for later phases: `GET /metrics` (Prometheus), `PUT /weights/{sha256}` + `weights_key` field (upload-once opponent cache).

## 5. Golden vectors — `testdata/`

Generated by `testdata/gen_golden.py` (seeded, reproducible). Consumed by `backend/pkg/brain/mlp_test.go` and `training/tests/test_parity.py`.

- `golden_mlp_tiny.json` — sizes [3,4,2], for debugging.
- `golden_mlp_full.json` — sizes [82,64,64,5].

Format: `{"sizes": [...], "weights_b64": "...", "input": [...], "expected_output": [...]}`. Tolerance: Go and Python forward must match `expected_output` to atol 1e-6.

## 6. Telemetry event schema v1 (WS-G)

One JSON object per event, Kafka topic `zhuch.events.v1` (emission gated on `KAFKA_BROKERS` env; no-op when unset):

```json
{"ts": 1760000000123, "source": "arena", "room": "eval-worker-3", "episode": "uuid-or-null",
 "type": "kill", "actor": "tank-id", "target": "tank-id-or-null",
 "pos": {"x": 100.0, "y": 200.0}, "data": {}}
```
`type` ∈ `spawn | kill | death | damage | pos_sample | episode_end`. `pos_sample` emitted at 1 Hz game time (every 20 ticks) per tank. `episode_end` carries the eval response stats in `data`.

## 7. Fitness (Python-side defaults, tunable knobs)

`fitness = w_score·score + w_kill·kills + w_surv·(survived_ticks / max_ticks)`
Defaults: `w_score = 1.0`, `w_kill = 200.0`, `w_surv = 100.0`. Expect to tune `w_kill` (reward-hacking risk: pacifist food farmers).

## 8. Prometheus metric names (WS-D)

Game server: `zhuch_tick_duration_seconds` (histogram, per room label), `zhuch_entities`, `zhuch_players`, `zhuch_bots` (gauges, room label), `zhuch_rooms` (gauge).
Arena: `arena_episodes_total` (counter), `arena_episode_duration_seconds` (histogram), `arena_ticks_total` (counter), `arena_inflight_evals` (gauge).

## 9. Scripted baseline bot

`backend/pkg/bots/scripted.go` — chaser/shooter: aim at nearest living enemy tank; move toward it, strafing perpendicular (sign flips every 40 ticks); fire when cooldown ready and target within 0.9·ViewRange; if no tank visible, seek nearest food. **Frozen after first release** — it is the eternal eval baseline; never rebalance it.
